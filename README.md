# Валера — демо трёх миссий

Windows x64: готовка, оборона двора и ремонт Нивы.

## Скачать

[Скачать демо ZIP — 1,99 ГБ](https://github.com/MyLittleCutie/valera-demo/releases/download/demo-3-missions-20261014/VALERA_DEMO_3_missions.zip)

[Короткая анкета плейтеста DOCX](https://github.com/MyLittleCutie/valera-demo/releases/download/demo-3-missions-20261014/VALERA_playtest_feedback.docx)

[Страница релиза](https://github.com/MyLittleCutie/valera-demo/releases/tag/demo-3-missions-20261014)

Распакуйте архив целиком и запустите `VALERA_DEMO.exe`. Файл `VALERA_DEMO.pck` должен оставаться рядом. Godot устанавливать не нужно. Файлы Source code на странице релиза не являются сборкой игры — скачивайте архив по ссылке выше.

Демо заканчивается после ремонта в третьей миссии. Выезд из гаража намеренно закрыт. Сохранения демо отделены от основной игры.

По умолчанию включён быстрый Vulkan. Если есть проблемы с графикой, в меню доступны другие режимы. Первая загрузка может занять больше времени, чем последующие.

## Обратная связь

Заполните короткую анкету и отправьте тому, кто пригласил вас на тест. Ошибки также можно описать в Issues: укажите миссию, действия перед проблемой и приложите скриншот. Не публикуйте личные данные.

Это тестовая сборка. Проверка на всех конфигурациях оборудования ещё не завершена. В этом репозитории распространяются готовая демо и анкета; исходники игры здесь не публикуются.
